# Библиотека компонентов: shadcn/ui

**Выбрана библиотека: shadcn/ui** (компоненты на Radix UI, стили на Tailwind CSS v4). Этот файл обязателен для агента и для людей: интерфейс собирается из её готовых компонентов, своих кнопок, полей и диалогов не пишем.

## Почему shadcn/ui

- Исходники компонентов лежат в самом проекте (`src/components/ui`), их можно подогнать под дизайн-систему «NestJS» (скругления, цвета, шрифты) без борьбы с чужой темой.
- Radix UI под капотом даёт то, что нужно для доступности: ловушка фокуса в диалоге, закрытие по Esc, возврат фокуса, ARIA-атрибуты, управление с клавиатуры.
- Тема задаётся переменными CSS: один файл `src/index.css` управляет цветами, шрифтами и скруглениями всех компонентов (см. `design-system.md`, раздел 8).
- Это тот же вариант, что показан в лекции.

Альтернативы (Material UI, Ant Design) отброшены: у них свой готовый вид, который пришлось бы переопределять, чтобы получить стиль из `design-system.md`.

## Какие компоненты берём

Устанавливаются командой `npx shadcn@latest add <имя>`.

| Компонент | Где используется |
|---|---|
| `button` | все кнопки: «Войти», «Создать аккаунт», «Добавить подписку», «Отмена», «Повторить», «Выйти» |
| `input` | email, пароль, название, сумма, интервал, дата начала |
| `label` | подпись каждого поля |
| `select` | период оплаты |
| `textarea` | заметка |
| `form` (react-hook-form + zod) | формы входа, регистрации, добавления: валидация и связь ошибок с полями |
| `dialog` | форма добавления подписки |
| `card` | карточка входа и регистрации, список подписок |
| `badge` | «Приостановлена» |
| `alert` | сообщения об ошибках формы и загрузки, «Войдите, чтобы продолжить» |
| `skeleton` | загрузка списка |
| `sonner` | уведомления «Подписка добавлена», «Аккаунт создан», «Сессия истекла» |
| `separator` | швы внутри списка |

Иконки: `lucide-react` (тонкие линейные, как в стиле). Другие библиотеки иконок не добавляем.

## Правила

1. **Только `src/components/ui`.** Кнопка, поле, диалог, выбор, карточка, бейдж, уведомление берутся оттуда. Своя вёрстка этих элементов запрещена.
2. **Не хватает компонента:** сначала проверить каталог shadcn/ui и добавить командой `shadcn add`, потом настраивать. Новые сторонние пакеты компонентов не подключаем.
3. **Оформление только через тему.** Цвета, скругления и шрифты берутся из переменных `src/index.css`. Жёстких цветов (`#fff`, `bg-[#0b0b0b]`) и произвольных размеров в экранах и компонентах быть не должно. Вариации внешнего вида добавляются в сам компонент (через `cva`), а не на месте использования.
4. **Составные элементы проекта** (строка подписки, поле пароля, рамка со свечением) собираются из компонентов `ui` и лежат в `src/components`. Дубликаты запрещены: прежде чем создать компонент, проверить, нет ли такого.
5. **Доступность Radix не ломаем:** не убираем `outline`, не заменяем `Dialog` своей вёрсткой, не перехватываем Esc и Tab.
6. **Перед генерацией агент называет компоненты,** которые собирается переиспользовать (формулировка из лекции), и только потом пишет код.

## Как это проверить

- В `src/` нет `<button`, `<input`, `<select`, `<textarea`, `<dialog` вне `src/components/ui`.
- В `src/` нет шестнадцатеричных цветов вне `src/index.css`.
- Все компоненты из таблицы действительно импортируются из `@/components/ui/...`.
