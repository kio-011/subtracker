# Subtracker: фронтенд

Интерфейс трекера подписок: регистрация и вход, список подписок, добавление подписки. Практика 8 («Добавляем фронтенд к проекту с помощью AI»). Бэкенд (FastAPI) лежит в `../backend`.

> Статус: часть 2 практики выполнена (интерфейс на shadcn/ui, единая тема, полный сценарий с настоящим API, состояния, защита от повторной отправки). Клиентские тесты (часть 3) ещё не написаны: раздел «Тесты» описывает то, что будет. Промпт, по которому собран интерфейс: [generation-prompt.md](generation-prompt.md).

## Основной сценарий

Человек с несколькими платными подписками входит в сервис (или регистрируется) и добавляет подписку. Результат: список его подписок, где новая видна с названием, суммой, периодом оплаты и датой ближайшего списания. Блок-схема: [scenario.md](scenario.md).

## Библиотека компонентов

**shadcn/ui** (Radix UI + Tailwind CSS v4). Интерфейс собирается из её готовых компонентов (кнопки, поля, диалоги, карточки, бейджи, уведомления), собственных аналогов не пишем. Почему и какие компоненты: [ui-library.md](ui-library.md).

## Оформление

Дизайн-система в стиле NestJS: тёмная тема, малиновое свечение, шрифты Manrope и Geist Mono. Цвета, шрифты и отступы заданы один раз переменными темы в `src/index.css`. Описание и правки под приложение: [design-system.md](design-system.md).

## Запуск

Нужны Node.js 20+ и запущенный бэкенд.

```bash
# бэкенд (из каталога backend; нужен PostgreSQL и файл .env, см. ../SPEC.md, раздел 7)
cd ../backend
./scripts/dev.sh --seed        # API на http://localhost:8000

# фронтенд
cd ../frontend
npm install
npm run dev                    # http://localhost:5173
```

Демо-аккаунт после `--seed`: `demo@example.com` / `demo-password`. Адрес API задаётся переменной `VITE_API_URL` (по умолчанию `http://localhost:8000`). Секреты в репозиторий не добавляются.

## Тесты

```bash
npm test          # все клиентские тесты (Vitest, Testing Library, MSW): 56 тестов
npm run lint
npm run build
```
