```text
Спроектируй интерфейс веб-сервиса «Subtracker»: трекер платных подписок (кто пользуется: человек, который хочет видеть свои подписки и сколько они стоят в месяц).

Технические требования: React + TypeScript + Tailwind CSS, компоненты shadcn/ui (Button, Input, Label, Select, Dialog, Card, Badge, Alert, Skeleton, Sonner/Toast). Не изобретай собственных кнопок и полей, используй shadcn/ui. Цвета, шрифты и отступы задай через CSS-переменные темы (токены), чтобы они были едиными.

Экраны:
1. Вход: email, пароль, кнопка «Войти», ссылка «Нет аккаунта? Зарегистрироваться».
2. Регистрация: email, пароль, повтор пароля, кнопка «Создать аккаунт», ссылка на вход.
3. Список подписок: шапка с названием и кнопкой «Выйти», заголовок «Мои подписки», кнопка «Добавить подписку», список карточек (название, сумма, период оплаты, следующая дата списания «через N дней», стоимость в месяц, бейдж «Приостановлена» для неактивных).
4. Диалог «Добавить подписку»: поля Название, Сумма, Период оплаты (месяц, год, неделя, свой интервал в днях), Интервал в днях (виден только для своего интервала), Дата начала, Заметка; кнопки «Добавить» и «Отмена».

Покажи для каждого экрана состояния (отдельными кадрами):
- Вход: исходное; ошибки полей (пустые email и пароль); отправка (кнопка «Входим…», поля недоступны); ошибка «Неверный email или пароль».
- Регистрация: исходное; ошибки («Введите корректный email», «Пароль должен быть не короче 8 символов», «Пароли не совпадают»); email уже занят.
- Список: загрузка (скелетоны), пусто («Подписок пока нет» + кнопка), успех с 4-5 подписками, ошибка загрузки с кнопкой «Повторить».
- Диалог: исходный; ошибки валидации рядом с полями; сохранение («Сохраняем…», поля недоступны); ошибка сохранения с сообщением, введённые значения сохранены.

Требования к доступности: у полей видимые подписи, ошибки рядом с полем и текстом, хорошо заметный индикатор фокуса, контраст текста достаточный. Основной сценарий выполняется с клавиатуры. Адаптивность: читаемо на ширине 360 px (карточки в одну колонку).

Стиль: спокойный, деловой, тёмная тема по умолчанию (светлую можно добавить), один акцентный цвет, скруглённые углы, много воздуха. Язык интерфейса: русский.
```
