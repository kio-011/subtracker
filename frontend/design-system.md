# Дизайн-система Subtracker (стиль «NestJS»)

Статус: утверждена как визуальное направление для практики 8. Источник: справочник стиля сайта NestJS (тёмная тема, малиновое свечение за затемнённым стеклом). Это основа для макета и для кода. Раздел «Адаптация для Subtracker» важнее исходного описания: он исправляет места, где стиль маркетингового сайта не подходит приложению с формами.

Тема: **только тёмная**. Светлой темы и переключателя нет.

## 1. Идея

Почти чёрная сцена, на которой единственный источник света это малиновое свечение. Свечение живёт в скруглённых рамках (экран входа и регистрации), всё остальное остаётся сажево-чёрным с тонкими линиями-швами в 1 пиксель. Заголовки крупные и лёгкие (Manrope, вес 500), весь рабочий текст набран светлым моноширинным шрифтом (Geist Mono), как вывод терминала. Единственная яркая заливка в интерфейсе это белая кнопка.

## 3. Типографика

| Шрифт | Где | Лицензия |
|---|---|---|
| **Manrope** (400, 500, 600, 700) | заголовки, навигация, кнопки | SIL OFL |
| **Geist Mono** (300, 400) | весь рабочий текст: подписи полей, описания, сообщения, числа | SIL OFL |

Оба шрифта доступны на Google Fonts и содержат кириллицу и символ рубля (проверено по таблицам диапазонов). Запасные: Inter и Arial для Manrope, JetBrains Mono, SFMono-Regular, Menlo, Consolas для Geist Mono. Шрифты подключаются локально (пакет `@fontsource`), без запросов к внешним серверам при работе приложения.

Заголовки без трекинга, вес 500 на любом размере.

### Шкала для приложения (адаптация исходной шкалы)

| Роль | Шрифт | Вес | Размер / интерлиньяж | Мобильный |
|---|---|---|---|---|
| display (заголовок экрана входа) | Manrope | 500 | 48 / 1,1 | 32 / 1,15 |
| page-title (заголовок страницы) | Manrope | 500 | 32 / 1,2 | 24 / 1,25 |
| card-title | Manrope | 500 | 22 / 1,4 | 20 / 1,4 |
| nav, button | Manrope | 500 и 700 | 16 / 1,5 | 16 / 1,5 |
| body (описания) | Geist Mono | 300 | 14 / 1,71 | 14 / 1,71 |
| field-label, error, hint, число | Geist Mono | 400 | 14 / 1,5 | 14 / 1,5 |
| input | Geist Mono | 400 | 16 / 1,5 | 16 / 1,5 |
| eyebrow | Geist Mono | 300 | 12 / 1,33, заглавные, трекинг −0,3px | то же |

Крупные размеры исходника (112, 128, 160 px) не используются: это шкала лендинга.

## 4. Отступы и скругления

- Базовая единица 4px. Отступ внутри карточки 20px (диалог 24px). Зазор между элементами 8px, между полями формы 16px. Расстояние между секциями страницы 40px (в оригинале 120px).
- Ширина контента до 1280px, боковой отступ 32px (мобильный 16px).
- Скругления: рамки 32px, навигация 32px, карточки 24px, поля ввода 24px, кнопки 20px, изображения 12px, индикатор 4px, бейджи 9999px.

## 6. Делай и не делай

Делай:
- Фон везде Soot Canvas, поверхности поднимай только до Carbon Panel и Graphite Slab.
- Заголовки Manrope 500 без трекинга; весь рабочий текст Geist Mono.
- Малиновый цвет только как свет (градиент в рамке), белая заливка только для главной кнопки.
- Разделяй швами 1px, а не заливками и тенями.

Не делай:
- Не заливай кнопки, бейджи и текст плоским `#ea2845`.
- Не делай заголовки жирными и не добавляй отрицательный трекинг.
- Не меняй абзацы на гротеск: рабочий текст в Geist Mono.
- Не используй мягкие тени для разделения.
- Не делай острые углы у рамок и кнопок.
- Не используй холодный сине-чёрный как фон.

## 7. Адаптация для Subtracker

Исходное описание сделано для маркетингового сайта. В приложении с формами нужно поправить следующее. Эти правила приоритетнее исходного описания.

| № | Проблема в исходнике | Решение |
|---|---|---|
| 1 | Граница Smoke Outline `#373535` на `#050303` даёт контраст 1,7, меньше 3:1, требуемых для границ полей ввода | Границы **полей и выбора** `#7d7b7b` (контраст 4,7 на Carbon Panel). Smoke Outline остаётся только у карточек и диалога |
| 2 | Нет индикатора фокуса | Кольцо фокуса 2px белое, отступ 2px, на любом интерактивном элементе (контраст 20,6). Не убирать `outline` |
| 3 | Нет цветов успеха и ошибки | Ошибка: Coral `#ff7b72` (текст и граница), фон ошибки `rgba(255,123,114,0.10)`. Успех: добавлен зелёный `#5fd3a1` (контраст 11,1) только для сообщения «Подписка добавлена» и бейджа. Это отступление от палитры |
| 4 | Лёгкий вес 300 мелкого текста плохо читается | Вес 300 только для описаний 14px и крупнее. Подписи, ошибки, подсказки, числа и текст полей вес 400 |
| 5 | Белый текст на `#ea2845` даёт контраст 4,3 | Текст не кладём на малиновую часть свечения: форму на экране входа размещаем на карточке Carbon Panel |
| 6 | Скругление 32px и свечение на узком экране | На ширине до 640px отступ рамки 16px, радиус 24px, заголовок 32px |
| 7 | Дрейф свечения | Отключается при `prefers-reduced-motion: reduce` |
| 7a | Заглавные подписи в фигурных скобках (`{ ПОДПИСКИ }_`) | Не используем: для приложения они лишние |
| 8 | Верхний размер шрифтов лендинга | Используем шкалу из раздела 3 |
| 9 | Высота поля 66px (в подписке на рассылку) | 48px, цель касания не меньше 44px |

## 8. Токены shadcn/ui

Тема описывается в `frontend/src/index.css` через переменные CSS (так принято в shadcn/ui). Все цвета, шрифты и скругления в компонентах берутся оттуда, жёстких значений в компонентах быть не должно.

```css
:root {
  --background: #050303;
  --foreground: #ffffff;
  --card: #0b0b0b;
  --card-foreground: #ffffff;
  --popover: #0b0b0b;
  --popover-foreground: #ffffff;
  --primary: #ffffff;
  --primary-foreground: #050303;
  --secondary: #1e1c1c;
  --secondary-foreground: #ffffff;
  --muted: #181818;
  --muted-foreground: #9b9a9a;
  --accent: #1e1c1c;
  --accent-foreground: #ffffff;
  --destructive: #ff7b72;
  --destructive-foreground: #050303;
  --border: #373535;        /* карточки и диалог */
  --input: #7d7b7b;         /* границы полей ввода, контраст не ниже 3:1 */
  --ring: #ffffff;          /* кольцо фокуса */
  --success: #5fd3a1;
  --warning: #ffa657;
  --link: #a5d6ff;
  --glow: linear-gradient(to right in oklab, #ea2845 0%, #780f20 50%, #050303 100%);
  --radius: 20px;           /* кнопки */
  --radius-card: 24px;      /* карточки, поля, диалог */
  --radius-frame: 32px;     /* рамки со свечением, верхняя панель */
  --font-sans: "Manrope", Inter, Arial, sans-serif;
  --font-mono: "Geist Mono", "JetBrains Mono", SFMono-Regular, Menlo, Consolas, monospace;
}
```

Тема только тёмная, поэтому блок `.dark` не нужен: значения заданы на `:root`, у `html` стоит `color-scheme: dark`.
